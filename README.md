# 🚀 DeFiFun

A decentralized finance platform for secure crypto asset management and trading.

## Features

- Wallet Connect
- Token Trading
- Portfolio Tracking
- Staking Dashboard
- Blockchain Integration

## Tech Stack

- Next.js
- React
- Tailwind CSS
- Ethers.js
- Solidity

## Installation

bash
npm install
npm run dev


## Deploy

Deploy on Vercel.
